# Prajwal Gouda Portfolio

Personal portfolio built with React and Vite. It presents my profile, experience, projects, skills, education, certifications, and contact details.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
npm run preview
```

## GitHub Pages deployment

The repository is configured to deploy the `my-portfolio` app automatically from the `main` branch.

1. Push changes to GitHub.
2. Open **Settings > Pages** in the GitHub repository.
3. Under **Build and deployment**, select **GitHub Actions** as the source.
4. Open the **Actions** tab and run the **Deploy portfolio to GitHub Pages** workflow if needed.

The public site will be available at:

<https://pajju1905.github.io/my-portfolio/>
